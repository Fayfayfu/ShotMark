# macOS 本地截图与 OCR 工具：设计规格

> 这是早期目标规格，包含尚未实现的跨屏拼接、云端 OCR、设置界面等内容。当前功能及限制请参阅仓库根目录的 [README](../../../README.md)，不要将本文视为已交付功能清单。

## 目标与边界

交付一个 macOS 原生菜单栏应用。用户按下全局快捷键 `Command + Shift + A` 后，可在所有显示器上框选截图，添加标注，离线识别图片文字并复制全部或选中的文字。

首版只支持 macOS，默认不保存截图历史、编辑状态或 OCR 文本。应用退出即销毁内存中的内容。

## 用户流程

1. 用户从菜单栏启动应用；首次截图时，应用引导授予屏幕录制权限。
2. 用户按 `Command + Shift + A`。应用获取所有显示器画面，显示深色全屏遮罩，并允许跨显示器框选。
3. 拖拽完成后，覆盖层显示选区尺寸和编辑工具栏。`Esc` 取消；`Command + C` 合成当前结果、复制 PNG 并退出；在框选内容内任意位置双击也执行相同操作。
4. 用户可继续编辑、撤销和重做。点击完成时，应用合成当前结果并复制 PNG 到剪贴板。
5. 用户点击 OCR 时，应用先用 Apple Vision 在本地识别；结果显示在可编辑文本面板中。用户可复制全部文字，或选择一段文字后复制选中内容。
6. 用户明确启用并配置云端 OCR 后，才允许把图片发送给该服务。离线识别失败时可以选择该备用服务；默认绝不上传。

## 标注交互

工具栏包含：矩形、圆形、划线、箭头、画笔、文字、马赛克、OCR、复制图片、撤销、重做、取消和完成。

矩形、圆形、划线、箭头和画笔均可选择颜色与线宽：2、4、6、8 px。文字可选择颜色、字号（14、18、24、32 px）和字重（常规、加粗）。每种工具记住本次会话中最近一次参数。

矩形、圆形、划线和箭头为矢量对象；画笔为路径；文字为可编辑文本对象；马赛克在导出时以选区内像素块效果渲染。所有对象按添加顺序绘制，支持撤销与重做。

## 组件与职责

### CaptureCoordinator

通过 Carbon `RegisterEventHotKey` 注册并监听 `Command + Shift + A`，检查屏幕录制权限，调用 ScreenCaptureKit 获取显示器图像，并控制一次截图会话的启动、取消、完成和清理。

### SelectionOverlay

管理全屏遮罩、跨显示器坐标、框选手势、尺寸提示、键盘事件和工具栏位置。它只负责界面状态，不保存图像或标注内容。

### AnnotationCanvas

持有原始截图、选区坐标和标注对象列表，提供绘制、选中、删除、撤销/重做和 PNG 合成接口。标注操作使用命令栈，避免逐帧保存完整位图。

### OCRService

默认以 Apple Vision 的文字识别请求完成离线 OCR，并输出纯文本与置信度。云端 OCR 以可配置适配器实现，只在用户显式选择时读取存储在 Keychain 的配置并发出请求。

### OCRResultPanel

展示可编辑的文本区域与“复制全部”“复制选中”按钮。无选区时“复制选中”不可用。复制操作写入系统剪贴板，不写入文件。

### MenuBarController 与 Settings

提供菜单栏入口、权限状态、保存副本开关、默认图片目录以及云端 OCR 配置入口。保存副本默认关闭。

## 权限、隐私与故障处理

- 缺少屏幕录制权限：不启动截图会话，显示明确原因，并提供打开系统设置的入口。
- 全局快捷键注册冲突：提示快捷键已被其他应用占用；菜单栏“开始截图”仍可用。
- OCR 失败：保持当前截图与编辑状态，显示错误；若已配置云端服务，用户可主动发起备用识别。
- 云端 OCR 失败：不自动重试、不落盘、不缓存上传；显示可复制的错误文本。
- 剪贴板写入失败、截图取消或多显示器捕获失败：保留可恢复的会话或明确退出，不产生空白文件。

## 技术选择

使用 Swift 与 AppKit。ScreenCaptureKit 负责截图，Vision 负责离线 OCR，Core Graphics/Core Image 用于合成和马赛克，NSPasteboard 用于复制，Keychain 用于云端 OCR 的密钥。使用现有 Command Line Tools 的 Swift Package Manager 编译和测试，再以本地脚本组装经 ad-hoc 签名的 `ShotMark.app`；不依赖完整 Xcode。

## 验收标准

1. `Command + Shift + A` 在成功注册时可唤起截图；若与其他应用冲突，菜单栏入口仍可用并显示冲突原因。
2. 单屏和多显示器环境下，框选与输出像素区域一致。
3. 每种标注能正确应用指定颜色和尺寸，撤销/重做顺序正确。
4. 点击完成、`Command + C` 以及框选内容内任意位置双击，均将合成 PNG 放入系统剪贴板并结束截图会话。
5. OCR 在断网时可用；结果可编辑，能复制全部和任意选中的片段。
6. 未显式启用云端 OCR 时，不产生任何网络请求。
7. 权限缺失、离线 OCR 失败和云端 OCR 失败都有可理解且可恢复的状态。
